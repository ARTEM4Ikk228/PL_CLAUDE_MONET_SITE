# Claude monet — сайт ресторану (Next.js 16)

Статичний сайт без бекенду: 5 сторінок (Головна, Меню, Про нас, Події, Контакти).

## Запуск локально
    npm install
    npm run dev

## Деплой на Vercel
1. Завантажте папку в GitHub-репозиторій і імпортуйте його на vercel.com/new
   (або виконайте `npx vercel` у цій папці).
2. Налаштування за замовчуванням підходять: Framework Preset = Next.js.

## Що замінити на реальні дані
- Адреса, телефон, email, соцмережі — `lib/data.js` (об’єкт `info`).
- Страви та ціни — `lib/data.js` (масив `menu`).
